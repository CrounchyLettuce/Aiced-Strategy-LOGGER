# Aiced Logger

A **test build** of Aiced Strategy that records a log of every match you play, so the developer can study how the game plays. It is not the real game and it is not on Google Play. Your progress here is kept separate from the real game's.

## Install on Android
1. Open the game's link in **Chrome**.
2. Tap the **three dots** (top right), then **Add to Home screen** (or **Install app**).
3. Open it from the home screen. The icon says **LOGGER**.

## Playing and sending a log
- Play normally. Everything is recorded on your phone only. Nothing is sent anywhere by itself.
- When a match ends, tap **Save log** on the end screen (or **Save match log** in the pause menu). A small file is saved to your phone's Downloads.
- Send that file to Henry. If you quit a match early, save the log anyway.
- Locked options (Deadly and others): Settings, tap the title four times, then press the button that appears twice (**Unlock everything**).

## What a log contains
Your taps and orders, once-a-second snapshots of the map, the match settings, and your browser and device name and screen size. No name, no account, no location.

## Updating
The page updates itself when you open it with a connection. If something looks old, close the app fully and open it again.
