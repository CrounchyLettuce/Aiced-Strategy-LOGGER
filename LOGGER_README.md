# Aiced Logger, Build 50
The wrap of the 49.9.x series. The Build 50 clean page is in the folder `50`; this is the same page plus the match logger.
Changed since 49.9.10: How to Play Rules rewritten in WC's order (Goal, Look around, Send troops, Send amount, Send from one base, Regroup, Lock on, Take a base, Grow, Get stronger, Special bases); the build label reads "Build 50"; leftover dead code and CSS removed; the What's new Build 50 entry has ten lines.
Things to try: open Play > How to Play and read the Rules top to bottom; open Settings and What's new and check the label; play one match and open the Result, Moments and Stats tabs.
Note: Grow is not WC's exact wording. WC's draft said the army "until its share is full" and "replaced from the same base"; the code has one global army limit that every base spawns under. See HANDOFF_50.md, item "Grow wording".
